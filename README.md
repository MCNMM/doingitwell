doingitwell
===========

Southern Nevada Health Pass organic lead generation package for finding Molina Healthcare of Nevada, SilverSummit Healthplan, and Nevada Medicaid Fee-for-Service members online.

## Included assets
- Static website homepage: `index.html`
- Autonomous lead generation command center: `autonomous-lead-system.html`
- Molina landing page: `molina-nevada-benefits.html`
- SilverSummit landing page: `silversummit-nevada-benefits.html`
- Nevada Medicaid Fee-for-Service landing page: `nevada-medicaid-fee-for-service-benefits.html`
- Printable benefits checklist: `checklist.html`
- Browser automation logic: `automation.js`
- Shared site styles: `styles.css`
- Daily execution plan: `marketing/daily-organic-lead-system.md`
- Organic post templates: `marketing/post-templates.md`
- Short-form video scripts: `marketing/video-scripts.md`
- Google Business Profile posts: `marketing/google-business-posts.md`
- Lead tracker CSV: `marketing/lead-tracker.csv`
- Autonomous operations playbook: `marketing/automation-playbook.md`
- Lovable build prompt, schema, Edge Functions, and launch checklist: `lovable/`

## How to use
1. Publish the HTML files to the Southern Nevada Health Pass website, Lovable, or any static hosting provider.
2. Add the plan-specific landing page links to the main site navigation.
3. Use the Google Business Profile posts once per week.
4. Publish one to two video scripts per day.
5. Use `autonomous-lead-system.html` to generate the daily queue, score leads, schedule follow-ups, generate compliant copy, and export leads.
6. Use the `lovable/` folder to recreate or upgrade the system inside Lovable for SNHP with persistent storage and scheduled automations.

## Compliance note
Use "may qualify" and "depending on your plan" in public content. Do not ask users to post Medicaid IDs, full dates of birth, diagnoses, or card photos in public comments. Confirm benefits directly with the plan or Nevada Medicaid before telling a member a specific benefit is available.
